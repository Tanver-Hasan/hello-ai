# Edgeword — Cloudflare AI Learning Lab

Edgeword is a progressive Cloudflare AI application and learning curriculum. It starts with a streaming Workers AI chat and incrementally adds durable memory, tool calling, AI Gateway protections, Auto Router, Clef decision routing, a React interface, Cloudflare Agents, retrieval, Workflows, MCP, and isolated code execution.

The deployed application is protected by Cloudflare Access:

**https://hello-ai.tanver-hasan.workers.dev**

## Features

- Workers AI chat with incremental streaming
- Persistent conversations with SQLite-backed Durable Objects
- Separate Streaming and Protected response modes
- Cloudflare AI Gateway authentication, logging, retries, DLP, and Guardrails
- `$5` fixed 30-day spend limit on each AI Gateway
- Clef-flash request classification
- AI Gateway Auto Router with explicit open-weight model pools
- Safe calculator tool calling
- React and Vite frontend
- Markdown and GitHub-flavored Markdown rendering
- Conversation creation, restoration, and deletion
- Mobile-responsive layout
- Learning Trace panel with routing weights, model, tokens, cost, and protection outcomes
- Cloudflare Agents sidecar state and RPC
- Separate resumable Agent Chat mode
- Worker and storage rate limiting

## Chat modes

### Streaming

```text
Prompt
  → Clef-flash
  → open-weight candidate pool
  → cloudflare/auto
  → hello-ai-streaming
  → SSE response
```

The streaming gateway uses request-only DLP. Response Guardrails and response DLP are not applied because they require the complete response.

### Protected

```text
Prompt
  → Clef-flash
  → open-weight candidate pool
  → cloudflare/auto
  → hello-ai-protected
  → prompt/response Guardrails and DLP
  → buffered JSON response
```

### Agent

Agent mode is an additional chat path backed by `EdgewordChatAgent`:

```text
/agents/edgeword-chat-agent/:instance
```

It provides separate SQLite message persistence, WebSocket delivery, resumable streaming, and an Agent-owned calculator tool. It does not replace or modify Streaming and Protected conversation storage.

## Routing

Clef-flash classifies each request:

```text
simple | complex | tool
```

Auto Router then chooses from the corresponding pool.

### Simple

```text
@cf/google/gemma-4-26b-a4b-it
@cf/openai/gpt-oss-20b
```

### Complex

```text
@cf/google/gemma-4-26b-a4b-it
@cf/moonshotai/kimi-k2.7-code
@cf/qwen/qwen3.8-27b
@cf/zai-org/glm-5.2
```

### Tool

```text
@cf/google/gemma-4-26b-a4b-it
@cf/moonshotai/kimi-k2.7-code
```

The candidate pool is available in the UI through the model tooltip and Model Settings dialog.

## Local development

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

Workers AI is remote during local development and may consume account allocation or incur charges.

Because the deployed Worker is behind Cloudflare Access, non-interactive development and tests may require an Access service token:

```bash
export CLOUDFLARE_ACCESS_CLIENT_ID="..."
export CLOUDFLARE_ACCESS_CLIENT_SECRET="..."
```

## Bindings

The Worker uses:

- `AI` — Workers AI
- `ASSETS` — React static assets
- `CONVERSATIONS` — core conversation Durable Objects
- `EdgewordAgent` — synchronized state and routing telemetry
- `EdgewordChatAgent` — separate resumable Agent Chat
- `CHAT_RATE_LIMITER` — chat and Agent connection protection
- `STORAGE_RATE_LIMITER` — history and telemetry protection

## Cost and abuse controls

- Chat requests: 10 per 60 seconds per client and Cloudflare location
- Storage requests: 60 per 60 seconds per client and location
- Request body: 16 KiB
- Prompt: 4,000 characters
- Core stored history: newest 40 messages
- Agent Chat history: newest 40 messages
- Streaming gateway: `$5` per fixed 30-day window
- Protected gateway: `$5` per fixed 30-day window
- Private requests skip AI Gateway cache

Worker Rate Limiting is permissive and eventually consistent. AI Gateway spend limits provide the inference-cost boundary. Worker, Durable Object, Workflows, Vectorize, AI Search, R2, MCP, and Sandbox costs require separate monitoring.

## Security notes

- Cloudflare Access protects the deployed hostname.
- The browser never receives Cloudflare API credentials.
- Model and tool output is treated as untrusted.
- Calculator arguments are independently validated.
- Agent and conversation identifiers are routing identifiers, not authentication.
- Production tenant ownership must be verified before state access.
- Telemetry responses omit prompts and model answers.
- Protected mode buffers responses so Guardrails and response DLP can inspect them before delivery.
